A single-emoji entry for make.fun's "One Emoji, One Smile" bounty ($5 in USDC): the program writes exactly one emoji — 🫶 HEART HANDS — to `entry.txt`, nothing else.

## The entry

The emoji is 🫶 (U+1FAF6, HEART HANDS): two hands forming a heart.

Why this one, against the judge's brief:

- **Warm at first glance** — a hand-heart is an unmistakable gesture of warmth, read instantly with no context needed.
- **Universal** — it needs no language, irony or in-joke, so a stranger of any age or background reads it the same way.
- **Chosen, not default** — it is not the first smiley that comes to mind, so it feels picked for the moment while staying instantly readable.
- **Right for a stranger** — it carries no intimacy, sarcasm or flirtation that would read oddly coming from someone unknown.

The program is pure Python stdlib, no network, no secrets: it writes exactly that one emoji (no trailing newline, no other text) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, falling back to `/output` when the variable is unset — inside the sealed gate's 1–8 character window.

## Run it

```sh
python3 main.py
```
